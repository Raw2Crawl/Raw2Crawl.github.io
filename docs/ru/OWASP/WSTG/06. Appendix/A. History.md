# A. История изменений

Руководство по тестированию версии 4 (Testing Guide v4) было опубликовано в 2014 году. История руководства началась в 2003 году, когда Дэн Катберт (Dan Cuthbert) выступил одним из его первых редакторов. В 2005 году проект перешел под руководство Эоина Кири (Eoin Keary) и был преобразован в вики-систему. С 2013 по 2018/2019 годы проект возглавлял Эндрю Мюллер (Andrew Muller) совместно с Маттео Меуччи (Matteo Meucci). Выпуск минорных обновлений после v4 и подготовку к масштабной версии v5 возглавляют Рик Митчелл (Rick Mitchell) и Эли Саад (Elie Saad).

- Апрель 2020: OWASP Testing Guide, Version 4.1
- Сентябрь 2014: OWASP Testing Guide, Version 4.0
- Сентябрь 2008: OWASP Testing Guide, Version 3.0
- Декабрь 2006: OWASP Testing Guide, Version 2.0
- Июль 2004: OWASP Web Application Penetration Checklist, Version 1.1
- Декабрь 2004: The OWASP Testing Guide, Version 1.0
