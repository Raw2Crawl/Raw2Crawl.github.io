## Добро пожаловать

> Мы делаем ставку на непрерывные инкрементальные улучшения, поэтому данный выпуск включает в себя множество обновлений. Мы стандартизировали формат тестовых сценариев для более комфортного чтения, сформулировали четкие цели для каждого сценария тестирования, объединили смежные разделы и добавили новые сценарии по актуальным темам тестирования.
>
> — Рик Митчелл (Rick Mitchell)

OWASP выражает искреннюю благодарность многочисленным авторам, рецензентам и редакторам за колоссальный труд, благодаря которому руководство достигло сегодняшнего уровня. Если у вас есть замечания или предложения по руководству по тестированию (Testing Guide), создайте Issue или отправьте свои исправления/вклад через Pull Request в наш [GitHub-репозиторий](https://github.com/OWASP/wstg/).
