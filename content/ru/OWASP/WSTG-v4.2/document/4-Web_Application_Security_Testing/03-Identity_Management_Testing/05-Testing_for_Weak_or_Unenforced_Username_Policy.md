# Тестирование слабой или необязательной политики имён пользователей

|ID          |
|------------|
|WSTG-IDNT-05|

## Краткое описание

Имена учётных записей часто имеют чёткую структуру: например, имя учётной записи Joe Bloggs — jbloggs, а Fred Nurks — fnurks. Поэтому действительные имена учётных записей легко угадать.

## Цели тестирования

- Определить, делает ли единообразная структура имён учётных записей приложение уязвимым для их перечисления.
- Определить, позволяют ли сообщения об ошибках приложения перечислять учётные записи.

## Методика тестирования

- Определите структуру имён учётных записей.
- Оцените ответы приложения на действительные и недействительные имена учётных записей.
- Используйте различия в ответах на действительные и недействительные имена для перечисления действительных имён учётных записей.
- Используйте словари имён учётных записей для перечисления действительных имён.

## Рекомендации по устранению

Убедитесь, что приложение возвращает единообразные общие сообщения об ошибках в ответ на неверное имя учётной записи, пароль или другие учётные данные, введённые при входе.
