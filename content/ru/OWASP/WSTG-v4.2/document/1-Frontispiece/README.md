# Сведения об издании

## Добро пожаловать

> Продолжая постепенно совершенствовать руководство, в этом выпуске мы внесли множество обновлений. Мы унифицировали формат сценариев, чтобы сделать чтение удобнее, добавили цели для каждого сценария тестирования, объединили разделы и включили новые сценарии по ряду современных направлений тестирования.
>
> — Rick Mitchell

OWASP благодарит многочисленных авторов, рецензентов и редакторов за усердную работу, благодаря которой руководство приобрело нынешний вид. Если у вас есть замечания или предложения по руководству по тестированию, создайте Issue или отправьте исправление либо дополнение через Pull Request в наш [репозиторий GitHub](https://github.com/OWASP/wstg/).
